# Modelo de fuga de clientes (churn)

Proyecto de laboratorio de la **Sesión 2 · Git y GitHub (parte 1)** del curso MLOps de UTEC Posgrado.

## Cómo ejecutarlo

```bash
pip install -r requirements.txt
python train.py
```

El script lee los hiperparámetros de `config.json`, entrena un Random Forest y muestra el **AUC** en el conjunto de prueba.

## Archivos

| Archivo | Para qué sirve |
|---|---|
| `train.py` | Entrena y evalúa el modelo |
| `config.json` | Hiperparámetros del experimento |
| `requirements.txt` | Librerías necesarias |
| `MISIONES.md` | Las misiones del laboratorio |
